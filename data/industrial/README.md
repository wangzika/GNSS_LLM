# 工业故障实验数据

当前唯一工业数据目录，按五步组织：

1. `01_preprocess/`：筛选、字段构造与训练／验证／测试划分。
2. `02_teacher/`：教师原始报告。
3. `03_review/`：验算、最终裁定与唯一训练文件。
4. `04_finetune/`：训练输入及小型训练统计。
5. `05_evaluation/`：纯输入／标签入口、当前学生预测与合并指标。

每步有 `input/` 和 `output/`；跨阶段使用相对链接，无重复数据副本。

全部文件用途、脚本名称、运行命令与结果统一写在 [工业故障流程文档](../../docs/industrial_fault_workflow.md)。数据来源和许可见 [数据说明](../DATASET_CARD.md)。
